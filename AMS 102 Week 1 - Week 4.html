1. Real Numbers & Simultaneous Equations

Properties and set classifications of real numbers (&mathbb;N, &mathbb;W, &mathbb;Z, &mathbb;Q, &mathbb;I, &mathbb;R), basic arithmetic laws, and techniques for solving simultaneous systems of linear and quadratic equations[cite: 3].

Real Numbers: ℝ = ℚ ∪ 𝕀
Simultaneous System: ax + by = c AND dx² + ey² + fx = g

2. Absolute Values & Linear Inequalities

Definitions and properties of absolute values alongside procedures for identifying and solving linear and absolute value inequalities[cite: 3].

|x| = x if x ≥ 0 ; |x| = -x if x < 0
|x - h| ≤ r ⟺ h - r ≤ x ≤ h + r

3. Indices & Logarithms

Fundamental laws of indices and logarithms, converting expressions to exponent form, and solving exponential and logarithmic equations[cite: 3].

aᵐ × aⁿ = aᵐ⁺ⁿ | (aᵐ)ⁿ = aᵐⁿ
logₐ(x) + logₐ(y) = logₐ(xy) | logₐ(xⁿ) = n logₐ(x)

4. Surds & Radical Expressions

Characteristics of surds, algebraic simplification, and techniques for rationalizing denominators using conjugate surds[cite: 3].

√(a × b) = √a × √b
Rationalizing: c / (a + √b) = c(a - √b) / (a² - b)

5. Polynomial Operations & Theorems

Polynomial terminology, structure, standard arithmetic operations, polynomial division, Factor Theorem, and Remainder Theorem[cite: 3].

Remainder Theorem: P(a) = Remainder when P(x) is divided by (x - a)
Factor Theorem: (x - a) is a factor ⟺ P(a) = 0

6. Rational Functions & Partial Fractions

Definition and algebraic operations on rational functions, along with systematic methods for partial fraction decomposition[cite: 3].

Distinct Linear Factors: P(x) / [(x - a)(x - b)] = A/(x - a) + B/(x - b)
Repeated Factor: P(x) / (x - a)² = A/(x - a) + B/(x - a)²

7. Fields & Ordered Fields

A field F is a set of elements equipped with addition (+) and multiplication (×) satisfying fundamental axioms: associativity, commutativity, distributivity, identities, and inverses[cite: 1, 3]. Distinguishes finite from infinite fields, and covers ordered field properties like trichotomy and transitivity[cite: 3].

Associativity: a + (b + c) = (a + b) + c | a × (b × c) = (a × b) × c[cite: 1]
Trichotomy: Exactly one holds: a < b, a = b, or a > b[cite: 3]

8. Fractional & Quadratic Inequalities

Solving rational fractional inequalities and second-degree quadratic inequalities, expressing solution sets in interval notation, and plotting solutions graphically on number lines[cite: 3].

Quadratic Inequality: ax² + bx + c ≤ 0
Rational Inequality: P(x) / Q(x) ≥ 0
